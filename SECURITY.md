# Security Policy for `sdlogin`

Version: **v0.1 (2026-07-31)**

## Supported Versions

Since this is a custom built project, specifically for the Curio Software Developer study, there are no supported versions. The project is maintained by the Curio team and is not intended for public use. However, since it is used in a production environment, we will provide security updates and patches as needed.

## Report a Vulnerability

If you find a security-related bug in `sdlogin`, we encourage you to report it to us privately. Please do not create a public issue for security vulnerabilities.

- [Submit Vulnerability Report for `sdlogin`](https://github.com/curio-team/sdlogin/security)
